# Architecture decision map

Architecture documents describe the current design. ADRs explain why that design was
chosen, what was rejected, and what consequences must be accepted. This map is the
traceability layer between them.

## Coverage rule

A normative architecture statement using “must”, “never”, “only”, or “required” must be
traceable to an accepted ADR, a user-provided platform requirement, or a security
baseline. New cross-cutting decisions update this map in the same change.
